# AI Skills Digital Passport

Issues, updates and verifies BTU's AI Skills Digital Passports. Confirmed skills come in from Google Sheets, every passport version is rendered to a multi-page PDF, its hash is anchored on Solana, and anyone can verify a passport without logging in.

Built by team **Git Happens** for the BTU AI Skills Digital Passport hackathon (October 2026).

Status: work in progress.
